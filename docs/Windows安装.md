# 用 Windows 把 ZZUPocket 装到 iPhone

不需要 Mac、Xcode，也不用修改源码。需要一台 Windows 电脑、一根能传输数据的线和你自己的 Apple 账号。

免费账号安装的 App 每 7 天需要刷新签名。这是目前免费侧载方案的维护要求。只有 iPhone、没有电脑的同学，请等待项目的 TestFlight 入口开放。

## 第一次安装，按顺序操作

1. **下载安装工具。** 在 Windows 浏览器打开 [Sideloadly 官网](https://sideloadly.io/)，下载 Windows 版并安装。按官网要求安装 Apple 的设备驱动及配套组件；如果装过不同来源的 iTunes，请先按官网指引处理冲突。
2. **下载 App 安装包。** 打开 [本仓库 Releases](https://github.com/Jerry-1092010180/ZZUPocket-iOS/releases)，在 Assets 中下载后缀为 `.ipa` 的文件。不要下载 Source code，也不用自己运行 Actions。如果页面没有 IPA，表示维护者尚未发布安装包，请等待；源码 ZIP 不能替代 IPA。
3. **连接手机。** 用数据线连接 iPhone，解锁，在手机提示中点“信任此电脑”，输入手机锁屏密码。保持手机解锁。
4. **开始安装。** 打开 Sideloadly，确认设备栏是自己的 iPhone，把下载的 IPA 拖进窗口，填写自己的 Apple 账号，点击 Start。需要密码和双重认证时，只在 Sideloadly 的登录提示中自行填写，不发送给维护者。
5. **允许开发者 App。** 根据手机提示，在“设置 → 通用 → VPN 与设备管理”中信任刚才自己的开发者身份。在“设置 → 隐私与安全性 → 开发者模式”中开启开发者模式，重启后再次确认。
6. **打开 ZZUPocket。** 回到手机主屏幕打开 App，再输入学校统一身份认证账号。Apple 账号用于安装，学校账号用于校园数据登录，是两个不同的步骤。

## 下周怎样继续用

在 Sideloadly 中按官网说明开启自动刷新。需要电脑开机、Sideloadly 的刷新服务运行，手机能被电脑连接；无线刷新还要完成设备 Wi-Fi 同步及相关网络设置。若电脑经常关机，最稳妥的做法是到期前用数据线连接电脑刷新。

如果 App 已经打不开，连接电脑后用同一 Apple 账号、同一 App 标识再次刷新或覆盖安装。不要先删除 App，以免丢失本地数据。更新 IPA 时也使用同一安装方式。

## 卡住了怎么办

| 现象 | 先这样处理 |
| --- | --- |
| 电脑看不到手机 | 换数据线或 USB 口，解锁手机并确认信任；检查官网要求的 Apple 驱动 |
| 开发者不受信任 | 在手机“VPN 与设备管理”中信任自己的开发者身份，联网验证 |
| 提示开发者模式关闭 | 到“隐私与安全性”开启，重启后再确认 |
| 一周后打不开 | 连接电脑刷新签名，不要删除 App |
| 免费 App 数量达到上限 | 免费账号有侧载数量限制，检查是否已安装其他侧载 App |
| 密码或验证码错误 | 在 Apple 官方账号页面确认账号可登录，不要把验证码发给其他人 |
